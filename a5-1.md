* Minimum length: Verify that a password containing exactly 8 characters and meeting the character requirements is accepted.

* Maximum length: Verify that a password containing exactly 20 characters and meeting the character requirements is accepted.

* Below minimum length: Verify that a password containing only 7 characters is rejected, even if it contains a digit and an uppercase letter.

* Above maximum length: Verify that a password containing 21 characters is rejected, even if it contains a digit and an uppercase letter.

* Missing required characters: Verify that a password is rejected if it does not contain at least one digit or one uppercase letter.
